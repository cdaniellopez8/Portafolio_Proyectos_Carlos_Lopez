# Portafolio_Proyectos_Carlos_Lopez

Este repositorio reúne una colección de proyectos, recursos y plantillas desarrollados por Carlos López como parte de su portafolio personal. Incluye:

- Plantillas y código en LaTeX utilizados en presentaciones académicas, informes y proyectos personales.

- GitHub Pages para la publicación de sitios y contenidos interactivos.

- Presentaciones de Power BI para el análisis y visualización de datos.

- Codigo utilizado en proyectos de Machine Learning, Redes Neuronales y analisis estadistico.

El objetivo de este repositorio es centralizar y documentar el trabajo realizado en diferentes áreas, facilitando su consulta, reutilización y actualización.
